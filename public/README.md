# 外贸业务员工具箱

一个无需安装、直接双击打开的本地外贸工作台，覆盖外贸业务员日常高频工作。

## 使用方式

直接用浏览器打开 `index.html` 即可，所有数据保存在浏览器本地，不需要联网。

## 功能模块

- 工作台：客户、报价、待跟进、全球时间、汇率速览
- 报价计算器：EXW / FOB / CFR / CIF 成本核算、成交方式填写引导、四条款成本利润对比、目标价反推、多币种报价
- 产品资料：维护型号、成本、包装、MOQ、供应商，一键带入报价
- 物流与装柜：多货物清单、装柜方案、集装箱利用率、堆叠建议、空运/快递计费重、运费四方式对比、方案复制
- 汇率换算：常用币种速查，支持在线更新和本地编辑
- 单位换算：长度、重量、体积、面积、温度
- 时区助手：客户城市时间与工作时间重叠判断
- 客户管理：客户档案、跟进日期、状态管理、客户详情、CSV 导出
- 报价记录：报价编号、客户、价格、付款/交期、状态跟进、CSV 导出
- 订单管理：PO 编号、金额、交期、港口、物流单号与全流程状态、摘要复制、CSV 导出
- 邮件模板：开发信、询盘、报价、催款、发货、售后、样品、展会等英文模板
- 贸易术语：Incoterms 2020 与付款方式速查
- 国家市场：主要目标市场的货币、时区、节假日、平台、认证与商务建议
- HS 编码：内置《中华人民共和国进出口税则（2025）》全量中文税号 10769 条（8 位税号 9454 条 + 品目/章 1315 条），叠加 24 条中国海关参考编码，含退税/监管/检疫字段，支持 CSV 导入导出
- 外贸英语：常用外贸词汇、例句与分类筛选
- 单证清单：海运/空运/快递单据核对，PI / CI / PL / SA / CO / B/L / AWB / BC 文本预览与 PDF 预览下载
- 设置与数据：公司信息、默认贸易条款/付款/港口/币种/交期，数据导入导出、重置演示数据

## 数据说明

客户、产品、订单、报价、汇率、HS 编码、内置单证模板、自定义邮件模板和单证勾选状态都保存在浏览器 `localStorage` 中。清除浏览器站点数据会清空这些内容，建议定期在“设置与数据”中导出备份。

## 局域网部署

仓库中的 `trade-toolbox-deploy` 是可直接部署到公司内部服务器的完整包：

1. 在服务器安装 Node.js LTS。
2. 复制 `trade-toolbox-deploy` 到服务器，双击 `start-server.bat`。
3. 服务器本机访问 `http://localhost:8080`，局域网访问 `http://服务器IP:8080`。
4. 按部署包内 README 放行防火墙端口即可。

当前版本数据保存在每位访问者自己的浏览器中；如需业务员共享同一份客户和订单数据，需要再增加数据库后端。
